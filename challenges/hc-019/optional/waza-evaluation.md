# Waza評価を安全に試す

**言語:** **日本語** / [English](../../../en/challenges/hc-019/optional/waza-evaluation.md)

## 目的

利用可能なWaza評価環境がある場合に、合成フィクスチャだけを対象として、評価の入出力境界を確認します。未知のコマンド、スキーマ、スコアを推測して作りません。

## 前提

- 承認済みのWaza拡張機能 / バイナリと公式ドキュメント
- 対応OS、固定されたツールのバージョン、実際のスキーマと操作方法
- モデル、データ送信、費用、出力の保存先を確認できること
- [固定本文](../starter/fixtures/draft-p.txt.template)だけを使える隔離された作業場所

## 権限・安全

- 拡張機能 / バイナリの取得と実行、モデルの利用、送信、費用を工程ごとに承認します。
- 入手元と署名またはハッシュを確認できないバイナリは実行しません。
- 非公開コード、秘密、第三者情報を送信しません。
- このリポジトリの不活性なテンプレートや通常のプロファイルは変更しません。

## 手順

1. 現在の公式ドキュメントで、入手元、対応OS、バージョン、スキーマ、操作方法を確認します。
2. 合成フィクスチャだけを含む作業用コピーを用意します。
3. 入力、モデル、送信先、費用、出力パス、後片付けの方法をレビューします。
4. 許可された操作を一段階ずつ行い、実際に使用した版と入力を記録します。
5. 出力を人が読み、固定2行の競合と直接対応する指摘だけを分けます。
6. スコアがある場合も、意味の正解、適用（application）、有用性（usefulness）へ一般化しません。
7. 自分が作成したコピー、プロセス、出力だけを終了・整理します。

## 観察すること

- 実際のスキーマと入力が一致したか
- ツール / モデル / 送信 / 費用の境界が明確か
- スコアと具体的な診断根拠を分けられるか
- エラーや未対応を成功として扱っていないか

## 停止条件

- 入手元、バージョン、スキーマ、操作方法、OS対応を確認できない
- バイナリ、モデル、送信、費用の承認がない
- 非公開データの送信や原本の変更が必要になる
- 後片付けの方法が不明
