# `sessionStart` Hook を限定的に観測する

**言語:** **日本語** / [English](../../../en/challenges/hc-038/optional/session-start-live.md)

[HC-038本編へ戻る](../README.md)

## 目的

承認済みの専用環境で、`sessionStart` の宣言、実際の呼び出し、チェッカーの終了コード、取得したログの範囲を分けて観察します。後続のツールに対する権限の強制を検証する手順ではありません。

## 前提

- 対象のリポジトリと default branch を確認できる。
- Cloud Linux / bash で実行できる固定したチェッカーがある。
- Copilot coding agent と必要な実行リソースを利用できる。
- ログ範囲、費用上限、停止担当、復元方法が決まっている。

## 権限と安全

- 有効な Hook とチェッカーの保存、セッションの開始、費用の発生について、個別の許可を得る。
- 既存の Hook を上書きせず、自分の変更だけを識別できるようにする。
- シークレット、プロンプト全文、顧客データをログへ残さない。
- 本編の `.template` を、そのまま実際に読み込まれるパスへ移さない。内容をレビューした別の実験用コピーを使う。

## 手順

1. チェッカーのリビジョン、ハッシュ、実行コマンド、タイムアウト、対象のブランチを記録します。
2. 既存の Hook と競合しない実験用の設定をレビューします。
3. 承認後に設定を反映し、Cloud セッションを1回だけ開始します。
4. Hook の宣言、呼び出しの記録、チェッカーの終了コード、標準出力と標準エラー出力、セッションの開始結果を別の項目として記録します。
5. `sessionStart` の成功から、後続ツールの権限判断を推定しないようにします。
6. 観察後、自分の変更だけを承認済みの手順で復元します。

## 観察すること

- 宣言したイベントと対象のリビジョン
- チェッカーの同一性
- 呼び出しの有無
- 終了コード、出力、タイムアウト
- ログに含めなかった機密情報
- 復元結果

## 停止条件

- default branch、チェッカーのバージョン、実行環境、ログの範囲が不明。
- 設定変更、セッションの開始、費用、復元の許可がない。
- 既存の Hook を安全に分離できない。
- `sessionStart` の成功を、後続ツールが保護された証拠として扱う必要がある。

## 本編へ戻る

結果を [HC-038の確認ポイント](../README.md#確認ポイント) に照らし、宣言、呼び出し、チェッカーの結果を混同していないか確認します。
