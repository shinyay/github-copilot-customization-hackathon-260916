# `preToolUse` Hook を限定的に観測する

**言語:** **日本語** / [English](../../../en/challenges/hc-038/optional/pre-tool-live.md)

[HC-038本編へ戻る](../README.md)

## 目的

承認済みの専用環境で、無害な1つのツール操作に対する `preToolUse` の呼び出しと権限判断を観察します。チェッカーの結果、fail-open、通常の権限判断、ツールの完了を別々に記録します。

## 前提

- 対象のリポジトリ、default branch、固定したチェッカー、Cloud Linux / bash を確認できる。
- 無害で scope が明確なツール操作を選べる。
- Copilot coding agent、対象のツール、必要な実行リソースを利用できる。
- 回数、時間、費用、ログ、停止、復元の上限が決まっている。

## 権限と安全

- 有効な Hook、チェッカー、限定したツール操作、費用、ログ取得について、個別の許可を得る。
- エンドポイントやファイアウォールの範囲を広げず、シークレットやプロンプト全文を記録しない。
- 破壊的なツール、広い書き込み権限、allow-all を使わない。
- 既存の Hook を上書きせず、自分の変更だけを復元できるようにする。

## 手順

1. チェッカーのリビジョン、ハッシュ、イベント設定、対象のツール、想定する安全な scope を記録します。
2. allow、deny、必要であれば1つの failure case を事前に選びます。回数の上限を超えて試さないでください。
3. 承認後に実験用の Hook を反映し、限定したツール操作を1回実行します。
4. 宣言、呼び出し、通信、終了コードや HTTP 応答、`permissionDecision`、通常のフロー、ツールの結果を別々に記録します。
5. タイムアウトや HTTP エラーをコマンドの deny と読み替えず、fail-open 後のツールの結果を別途確認します。
6. 観察後、自分の変更だけを復元します。

## 観察すること

| 層 | 記録 |
|---|---|
| Hook | イベント、リビジョン、呼び出し |
| チェッカー | コマンド / HTTP、終了コード、応答、タイムアウト |
| 権限判断 | decision と reason、通常のフローへの復帰 |
| ツール | 実行されたか、完了したか、結果 |
| 安全性 | scope、上限、ログ、復元 |

## 停止条件

- チェッカー、default branch、対象のツール、権限判断を観測できる範囲が不明。
- エンドポイントやファイアウォールの変更、秘密情報、プロンプト全文のログ、破壊的な操作が必要。
- タイムアウトや HTTP エラーを、実際のツール完了として扱う必要がある。
- 個別許可または復元方法がない。
