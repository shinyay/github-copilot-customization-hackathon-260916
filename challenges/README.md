# Challenges

公開中Challengeは[Challenge Index](../docs/generated/challenge-index.md)から選んでください。各ChallengeページにはStory、機能説明、Starter Kit、設計、比較、Evidence、提出、審査、Fallbackがすべて含まれます。

Starter PackはHub内では不活性です。Runtime consumerは `--condition` を必須とし、`pack/payload/**/*.template` を `.hackathon/challenge/**` へbyte copyするだけです。参加者はStarterを読み、必要な場合だけ、そのconditionに許可されたactive artifactを新規作成します。設定を有効化せず、不活性な設計資料や調査の分け方を比較するChallengeもあります。

過去のLABは前提ではありません。Challengeページと
[Getting Started](../docs/getting-started.md)、
[Runtime Repository Guide](../docs/runtime-repository-guide.md)
だけで開始できます。
