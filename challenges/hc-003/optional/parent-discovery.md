# 親リポジトリからのカスタマイズ検出を調べる

**言語:** **日本語** / [English](../../../en/challenges/hc-003/optional/parent-discovery.md)

[HC-003 本編へ戻る](../README.md)

## 目的

リポジトリのサブディレクトリだけをワークスペースとして開いたとき、利用中のクライアントが親リポジトリのカスタマイズをどのように検出するかを、本編とは別の安全な環境で観察します。

`chat.useCustomizationsInParentRepositories` は、対応する VS Code で親リポジトリからの検出を制御する設定です。既定値や前提は、バージョンごとに公式説明を確認してください。設定名を知っているだけでは、未知の親リポジトリを信頼したり、機能を有効にしたりする許可にはなりません。

参考:

- [VS Code Custom instructions](https://code.visualstudio.com/docs/agent-customization/custom-instructions)
- [Monorepo customization discovery](https://code.visualstudio.com/docs/agent-customization/overview#_use-customizations-in-a-monorepo)

## 前提

- 自分が管理する、破棄または元に戻せる親リポジトリを用意できる
- 親リポジトリと、ワークスペースとして開くサブディレクトリの境界を説明できる
- 現在のクライアントとバージョンで、親リポジトリからの検出に対応しているか、設定がどうなっているかを確認できる
- ワークスペース、親リポジトリ、対象ソースの違いを本編とは別に記録できる
- 新しい会話を用意できる

`.git` の構成やワークスペースの境界が公式説明の前提と異なる場合は、同じ挙動だと一般化せず、作業を止めます。

## 権限と安全

- 親リポジトリを trust してよいかどうかは、その所有者が判断します。
- 内容を理解していない親の `AGENTS.md` や、ほかのカスタマイズを読み込ませません。
- 既存の親ファイル、home/User/organization 設定、Memory は変更、削除、退避しません。
- 他人のリポジトリには書き込まず、trust やポリシーを迂回しません。
- シークレット、非公開データ、ローカル環境の個人情報を記録に含めません。

## 手順

1. 自分が管理する使い捨ての親リポジトリと、その中でワークスペースとして開くサブディレクトリを用意します。
2. 親リポジトリ、サブディレクトリ、`.git` の位置、ワークスペースルートを、図または短いメモで区別します。
3. 現在のクライアントとバージョン、親リポジトリからの検出への対応状況、設定値を記録します。設定変更が必要な場合は、所有者の許可と元の値を確認します。
4. 親リポジトリに、出力形式など影響のない観察用規則だけを記述した短い `AGENTS.md` を新しく作成します。既存のファイルがある場合は上書きせず、中止します。
5. サブディレクトリだけをワークスペースとして開き、新しい会話で短い読み取り依頼を送ります。
6. 親ファイルの保存、クライアント上での検出、本文利用を示す情報、回答を分けて記録します。明示的に添付した試行は、親からの自動検出と分けます。
7. ワークスペースをリポジトリのルートで開いた場合と比較する必要があれば、入力条件が変わることを明記し、別の新しい会話で行います。
8. 自分が作成したファイルと、変更した設定だけを元に戻します。

## 観察すること

- 親リポジトリと、開いたワークスペースの境界
- クライアントが親の参照元を表示したか
- 親本文が利用されたと確認できる範囲
- ワークスペースの開き方による、ソースや参照可能範囲の違い
- ルートへ手動で配置した場合や、明示的に添付した場合との違い
- trust、権限、設定について未確認の箇所

回答が観察用の形式になったことだけで、親から自動検出されたとは判断しません。

## 停止条件

- 親リポジトリの所有者、信頼性、ワークスペースの境界のいずれかが不明
- 既存の親ファイルや共有設定を変更しないと試せない
- クライアントの対応状況や、変更した設定を元に戻す方法が分からない
- trust や organization ポリシーの回避が必要
- 本編と入力条件を分離できない

停止した場合は「未確認」として終え、親を利用できないことを、本編で使うルートの `AGENTS.md` の失敗とは扱いません。
