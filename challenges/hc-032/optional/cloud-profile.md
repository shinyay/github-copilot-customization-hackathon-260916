# Cloud Agent で profile を観測する

**言語:** **日本語** / [English](../../../en/challenges/hc-032/optional/cloud-profile.md)

[← HC-032 のメインシナリオ](../README.md)

## 目的

承認済みの専用リポジトリで、Custom Agent profile の保存元、選択、リビジョン、実効ツール、実際の呼び出しを、範囲を限定して観測します。

## 前提

- Cloud Agent と対象リポジトリを利用できる
- 開始ブランチと、profile の保存元となるリポジトリ/ref/ファイルを特定できる
- control と investigation profile の生のバイト列を保存できる
- モデル、費用、試行回数の上限を決められる

## 権限と安全

- active profile の保存、選択、Cloud Agent のタスク、モデルの利用、終了時の解除について事前承認を得ます。
- 役割本文を ACL とみなさず、危険な書き込み/投稿コマンドで制限を試しません。
- 自分が追加した profile だけを解除し、共有設定や履歴を消しません。

## 手順

1. profile のリポジトリ/ref/ファイル、生のハッシュ、表示名を記録します。
2. control または investigation profile を明示的に選択します。
3. 同じ `approval-trace` の依頼を使い、タスクを 1 回だけ実行します。
4. selection、実効ツール、実際の呼び出しを直接確認できる記録だけ転記します。
5. ソースに結び付く根拠、unknown、引き継ぎ内容の品質を確認します。
6. 実験後は自分が追加した active profile を解除します。

## 観測すること

- 保存された profile と選択された profile の一致
- 宣言したツールと実効ツールの差
- actual call の ID、ツール、入力、結果
- role 本文の禁止事項と実権限の違い
- ソースの範囲外にある事実を作り上げていないか

## 停止条件

- 利用資格、承認、開始ブランチ、profile のバイト列のいずれかが不明
- モデル、費用、回数上限が決まっていない
- 宣言したツールだけから、実効ツールや呼び出しを推測する必要がある
- 書き込み/投稿操作や共有設定の変更が必要になる
