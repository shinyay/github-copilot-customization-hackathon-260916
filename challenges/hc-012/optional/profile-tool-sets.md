# ProfileでTool Setを安全に確認する

**言語:** **日本語** / [English](../../../en/challenges/hc-012/optional/profile-tool-sets.md)

このガイドは[HC-012本編](../README.md)の補足です。本編はProfileを変更しなくても完了できます。

## 目的

不活性なTool Setの原稿を、専用Profileで検出、選択、解除できるか確認します。宣言したメンバー、UIで選んだメンバー、有効なツール、実際の呼び出しをそれぞれ観察します。

## 前提

- Tool Setsに対応するVS CodeとCopilotを利用できる
- `Chat: Configure Tool Sets` と固定された四つの参照を本人が確認できる
- 既存設定と分離できる専用Profileを用意できる
- 組織ポリシーと環境所有者がProfile設定の追加を許可している

## 権限と安全

- Tool Setは権限を追加せず、元のツールの承認や利用資格を変更しません。
- `starter\customization\reader.toolsets.jsonc.template` は不活性な原稿です。このリポジトリ内では接尾辞を外しません。
- 既定Profile、同期設定、既存Tool Setを削除・上書きしません。
- 実際のパス、アカウント名、認証値、生の業務データを共有記録に残しません。

## 手順

1. 本編で固定された四つの参照と集合の原稿を確認する。
2. 専用Profileへ切り替え、`Chat: Configure Tool Sets` から新しいTool Setsファイルを作成する。
3. UIが開いた場所が現在のProfileのpromptsフォルダーで、ファイルの接尾辞が `.toolsets.jsonc` であることを確認する。`.vscode` や推測した `HOME` のパスへ手作業で配置しない。
4. スターターのサンプルの内容を、新しく作成したファイルへコピーする。固定された四つの参照以外は追加しない。
5. エディターの補完と診断を確認し、ピッカーで集合を展開して四つの参照を照合する。
6. 集合を選択し、他の選択経路から余分なツールが有効になっていないか、製品で確認できる範囲を調べる。
7. 所有者が許可した読み取り専用の固定依頼を一度だけ実行する。実際に呼ばれたツール、入力、返却値、承認を記録し、すべてのメンバーの呼び出しを強制しない。
8. 今回作成した集合の選択を解除し、今回作成したファイルだけを削除する。元の選択状態を確認する。

## 観察すること

- 原稿に宣言した四つの参照
- ピッカーで展開・選択した四つの参照
- 他の選択経路を含む有効なツール
- Agentが実際に呼び出したツール
- 初回作成と再設定で迷った箇所
- 集合を使わない方が明確な場面

原稿を保存できたことだけを根拠に、検出、選択、呼び出しまで成功したとは判断しません。

## 停止条件

- 対応UI、固定された四つの参照、利用資格、所有者の承認のいずれかを確認できない
- current Profileの保存先や既存設定との分離を確認できない
- 固定された四つの参照とピッカーのメンバーが一致しない
- ツールの追加、権限の変更、既存設定の削除が必要になる
- 今回追加した集合だけを安全に解除できない

停止した場合は、本編の不活性原稿と紙上の再構成へ戻ります。
