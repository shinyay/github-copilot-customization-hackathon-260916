# utility modelの経路を観察する探索ガイド

**言語:** **日本語** / [English](../../../en/challenges/hc-017/optional/utility-models.md)

## 目的

[HC-017 の本編](../README.md)で扱うChat modelとは別に、コミットメッセージの生成など、一つのutility modelの経路を観察するための補足ガイドです。Chatのピッカーで選んだモデルを、utility機能の実効モデルとはみなしません。

## 前提

- 対象を一つのutility機能に限定できる
- 同じ非機密の固定入力と、同じワークスペースの状態を用意できる
- 対応するクライアント、Copilot、utility機能を利用できる
- 実効モデルの表示または観測方法を公式資料で確認できる
- 設定変更が必要な場合、自分の変更だけを元へ戻せる

## 権限と安全

- utility機能による生成、実効モデルの観測、必要な設定変更について、事前に許可を得ます。
- コミット、プッシュ、プロバイダーの登録、認証情報の変更は行いません。
- 非公開コードや顧客情報を固定入力にしません。
- 生成物をリポジトリに保存しません。

## 手順

1. 観察するutility機能を一つ選び、Chatとの入力経路の違いを確認します。
2. 非機密の固定入力、ワークスペースの状態、生成前の設定を記録します。
3. 実効モデルを観測できるUIまたは公式手順があるか確認します。
4. 許可がある場合だけ一度生成し、表示と生成結果を記録します。
5. 同じ入力を通常のChatへ渡した結果を、utility経路の代替観測として扱いません。
6. 自分が変更した設定だけを元へ戻し、復元を確認します。

## 観察すること

- utility機能と入力経路
- 固定入力とワークスペースの状態
- 要求設定と観測できたモデル表示
- 生成結果と欠測
- Chat modelの選択との関係
- 後片付け後の状態

utility機能の一つの観測結果を、Chat modelの実効経路や本編の品質比較に当てはめません。

## 停止条件

- utilityの入力経路または実効モデルを確認できない
- 追跡できない User / Profile 設定変更が必要
- プロバイダーの登録、認証情報の変更、コミット、プッシュが必要
- 非公開コードを使わなければ観察できない
- 自分の変更だけを安全に戻せない
