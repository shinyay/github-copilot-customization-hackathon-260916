# Agent Host で BYOK を評価する探索ガイド

**言語:** **日本語** / [English](../../../en/challenges/hc-017/optional/host-byok.md)

## 目的

[HC-017 の本編](../README.md)やローカルクライアントのBYOKとは別に、Agent Hostからプロバイダーを利用する経路を安全に観察するための補足ガイドです。ローカル環境での接続成功を、Hostでの成功として扱いません。

## 前提

- 対応する Agent Host と実行 OS を確認できる
- 必要なExperimental設定、プロバイダー、実際のモデルID、secure inputの利用条件を確認できる
- Host、Copilot、プロバイダー、モデルの利用資格と組織ポリシーを確認できる
- Hostの実行場所、プロファイルデータ、設定の保存先、ローカルクライアントとの違いを記録できる

## 権限と安全

- Experimental設定、プロバイダーの登録、認証情報の入力、Hostからの初回通信、費用の発生について、個別に許可を得ます。
- 送信候補は承認済みの無害な合成文だけにします。
- 非公開コード、本編の固定入力、既存のプロファイルデータ、通常のUser設定は送信も変更もしません。
- シークレットをリポジトリやログに残しません。

## 手順

1. Hostが対応するOS、設定面、プロバイダー、実行場所を公式資料で確認します。
2. ローカルクライアントとHostで共有される設定、共有されない設定を整理します。
3. 開始前のHost設定、選択されていたプロバイダー、確認できる範囲を記録します。
4. 必要な許可がすべて得られた場合に限り、Host側の公式手順でプロバイダーを選び、無害な合成文を一度送ります。
5. Host上で観測できたモデル表示、応答、費用の情報を記録します。
6. 自分が変更したHost設定だけを元に戻し、復元を確認します。

## 観察すること

- Host と実行 OS
- ローカルクライアントとの設定の違い
- 要求したプロバイダー / モデルと、観測した表示
- secure input、通信、応答、費用の確認結果
- 後片付け後のHostの状態

Hostで一度応答したことは、本編のモデル比較、ローカル経路、非公開タスクの品質を示すものではありません。

## 停止条件

- 対応するHost / OS、Experimental設定、プロバイダー、認証情報、費用に関する許可が揃わない
- ローカルクライアントでしか確認できない
- 非公開コード、本編の固定入力、通常のプロファイルの変更が必要
- Host 側の変更だけを安全に戻せない
