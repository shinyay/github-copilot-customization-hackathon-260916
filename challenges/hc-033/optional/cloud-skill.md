# Cloud Agent で Skill を観測する

**言語:** **日本語** / [English](../../../en/challenges/hc-033/optional/cloud-skill.md)

[← HC-033 のメインシナリオ](../README.md)

## 目的

承認済みの専用リポジトリで、Skill の discovery、body の利用、resource の読み取りを、範囲を限定して観測します。最初の確認ではスクリプトを実行しません。

## 前提

- Cloud Agent と対象リポジトリを利用できる
- 開始ブランチと Skill の保存元/ref/ファイルを特定できる
- Skill の本文とすべてのリソースの生のバイト列を保存できる
- リソースの内容を安全面からレビュー済み

## 権限と安全

- active Skill の保存、Cloud Agent のタスク、モデル、費用、終了時の解除について事前承認を得ます。
- 実際の CSV、DB、import、replay、本番データは使いません。
- スクリプトは初期の適用範囲から除外し、リンクがあっても実行しません。

## 手順

1. Skill とリソースの保存元、リビジョン、個別のハッシュを記録します。
2. `replay-plan` または `journal-boundary` の一方を、固定依頼で実行します。
3. description、body、resource の各段階を直接確認できる記録だけ残します。
4. ソースに結び付く根拠、DB に関する unknown、停止条件を確認します。
5. 実験後は自分が追加した active Skill だけを解除します。

## 観測すること

- Skill が候補として見えたか
- body が使われたことを直接確認できるか
- チェックリストが読まれたことを直接確認できるか
- スクリプトが未実行のままか
- リンクや似た回答だけから利用を推測していないか

## 停止条件

- 利用資格、承認、開始ブランチ、Skill/リソースのバイト列のいずれかが不明
- リソースの安全面のレビューが完了していない
- スクリプト、DB、import、replay を実行しないと確認できない
- モデル、費用、回数上限が決まっていない
