# 外部評価ツール / サービスを検討する

**言語:** **日本語** / [English](../../../en/challenges/hc-027/optional/external-evaluation.md)

[メインシナリオへ戻る](../README.md)

## 目的

合成した18行の演習とは別に、外部の評価ツールやサービスを使う場合の確認手順を整理します。名称からコマンド、対応モデル、料金、送信範囲を推測せず、一次資料で確認できた最小限の構成だけを試します。

## 前提

- 発行元、公式配布元、対応バージョン、利用条件を確認できる
- 認証方法、対象モデル、サービスの利用資格を確認できる
- 送信されるプロンプト、応答、ソース、メタデータを説明できる
- 独立した検証環境と費用上限を用意できる

## 権限・安全

- ダウンロード、インストール、ログイン、モデルの利用、外部送信、課金を個別に承認します。
- 非公開のプロンプト、ソース、トークン、個人情報を無承認で送りません。
- 公式に確認できないコマンドや非公式のバイナリは試しません。
- 合成結果を、実際のモデル性能や教育効果の測定値に置き換えません。

## 手順

1. 発行元、バージョン、バイナリ / サービスの公式URL、チェックサムの提供有無を記録します。
2. データフロー、保持期間、学習への利用、リージョン、削除方法を確認します。
3. メインシナリオと同様に、ルーブリック、分母、順序、停止条件、欠測、費用上限を結果を見る前に固定します。
4. 非公開データを含まない、最小限の合成サンプルを用意します。
5. 承認済みの方法で1回だけ実行し、ツールのバージョン、モデル、入力範囲、エラー、所要時間、費用を記録します。
6. 想定外の送信、権限要求、費用、結果形式があれば追加実行を止めます。
7. 外部評価の記録を、メインシナリオの合成した18行とは別に保存します。

## 観察すること

- 発行元 / ツールまたはサービス / バージョン
- 認証 / 権限
- モデル / リージョン / 送信データ / 保持期間
- ルーブリック / サンプルの識別情報 / 実行結果
- 所要時間 / 費用 / エラー
- 後片付け / 削除の確認

## 停止条件

- 発行元、バージョン、公式の取得元を確認できない
- インストール、ログイン、外部送信、モデル、課金の承認がない
- 非公開データを送信対象から除外できない
- データの保持期間、リージョン、削除方法を確認できない
- 対応コマンドや料金条件を一次資料で確認できない

停止理由を記録し、[メインシナリオ](../README.md)のローカル合成評価へ戻ります。
